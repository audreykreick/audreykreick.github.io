CSS property: Colors

    What did I look up?

In Google, I searched "CSS Property: Colors"

    What sites did I consult?

Mozilla.org, a website designed by developers, for developers. It includes information on CSS, JavaScript, HTML, and much more.

    https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/color

W3Schools.com, a site made to teach people how to code. It has video tutorials, ways to get certified, and information on various coding languages.

    https://www.w3schools.com/cssref/pr_text_color.php

Elementor.com, a website created to build websites. They assist people in creating websites and have different blogs describing coding methods

    https://elementor.com/blog/colors-in-css/

GeeksforGeeks.com, a site for anyone to learn coding methods including web development, programming languages, and different softwares.

    https://www.geeksforgeeks.org/css/css-color-property/
    What are the differences in the information presented on each site?

Mozilla.org Describes what CSS color values, are how to use them, and links an additinal article for HTML colors. The article features ways to use colors where the reader can easily copy and paste it into their code. It also goes into how to make your website accessible for everyone by using certain colors. Lastly, it also has examples and information on browser compatibility.

M3Schools.com Has text boxes where readers can look at the code already there and open a demo to try it out themselves. It also shows each browser and what kind of colors it supports. This resource mainly has examples and demos to try.

Elementor.com Goes into CSS and HTML colors and their propertes, codes, keywords, and names. They start with a quick intro about the importance of colors in a website design, which none of the other sites have. In addition, there is a huge table with tons of colors and their name and CSS value.

GeeksforGeeks.com Specifies what the color property is used for and what kind of color values CSS accepts. It dives into property values, using color keywords, outputs, RBG values, and other values.

      Examples of code in the specified languages

    Do any of your 4 resources stand out as particularly good or bad?

I think Mozilla.org is the best resouce of the four. It provides the most information regarding what color values are, how to use them, and additional resources. In addition to basic info, it also allows users to copy and paste the code easily.

The worse site of the four is M3Schools.com. While the information can be useful, it really only provides demos and examples to try.
