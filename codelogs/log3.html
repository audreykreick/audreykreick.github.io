Code Log 3: CSS Media Queries

How does a CSS media query work, and why is it useful?

The term absolute when talking about CSS length units means that the units are not relative to anything else. They are generally considered to always be the same size. Most absolute units are more useful when used for print, instead of screen output. Relative lenth units, on the other hand, are relative to something else. A benefit of using relative units is that you can make it so that the size of text or other elements scales are relative to everything else on the page.
