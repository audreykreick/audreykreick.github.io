Code Log 3: CSS Media Queries

How does a CSS media query work, and why is it useful?

A CSS media query works by checking specific characteristics of a user’s device or browser (EX: screen width, height, orientation, user preferences, etc.) and applying certain styles only when those conditions are met. Media queries begin with the @media keyword, followed by one or more conditions written in parentheses. If the device or browser matches those conditions, the CSS inside the media query is applied. If not, those styles are ignored.

Media queries are especially useful for responsive web design. They allow developers to create layouts that adapt to different screen sizes, like desktops, tablets, and smartphones. They can also detect features like whether a device uses a touchscreen or a user’s preferred color scheme. Overall, media queries make websites more flexible, accessible, and user-friendly by ensuring the design adjusts to different environments.

What "media features" are supported by media queries, and what do they do?

The media features that are supported by queries include width/ height, aspect-ratio, orientation, and resolution.

Width/ Height

    These features are used to create layouts that respond to different screen sizes. The width (and height) media features can be used as ranges, and therefore be prefixed with min- or max- to indicate that the given value is a minimum, or a maximum.

Aspect-ratio

    This feature defines the width-to-height aspect ratio of the viewport. You can use the aspect-ration, min-aspect-ratio, max-aspect-ratio characteristics to set styles depending on the aspect ratio of the viewport.

Orientation

    This feature defines the way the screen is oriented, such as tall (portrait) or wide (landscape) based on how the device is rotated.

Resolution

    The resolution, min-resolution, and max-resolution characteristics can be used when you want to set styles depending on the device’s pixel density.
