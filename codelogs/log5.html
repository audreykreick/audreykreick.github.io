Besides background-image, background-color and background-attatchment can also be used to affect the display of background images. Background-color sets the background color for a page. Background-attatchment sets whether a background image scrolls with the rest of the page, or is fixed.

    In one sentence, how would you define the differences between dimensions and resolution in a bitmap image?

Dimentions describe the width and height of the image in pixels (1000x1000), while resolution describes the density of the pixels within a space (200 PPI).

    What are the similarities and differences between these image file formats? Why are some better than others for specific uses?

GIF: A good choice for basic images and animations.

PNG: A PNG is favored over a JPEG for more precise reproduction of source images, or when transparency is needed.

JPG/JPEG: A good choice for lossless animation sequences.

PNG and GIF use lossless algorithms, ensuring the image stays sharp regardless of how many times it is saved. JPG uses lossy compression that averages nearby pixels, which can cause blurring or noise around sharp edges or text. For file size, JPGs generally have the smallest file sizes for complex photos. PNGs are typically the largest. PNG is the best choice for images with transparent backgrounds, as this format handles it much better by allowing varying degrees of opacity, leading to smoother edges.
