Code Log 4: CSS Color

The color CSS data type represents a color. A color may also include a transparency value, showing how the color should show with its background. A color can be specified with the following methods:

What do these CSS properties do?

color

Represents a color.

background-color

Sets the background color of an element.

border-color

Sets the color of an element's border.
