Code Log 4: CSS Color

The color CSS data type represents a color. A color may also include a transparency value, showing how the color should show with its background. A color can be specified with the following methods:

What do these CSS properties do?

color

Represents a color.

background-color

Sets the background color of an element.

border-color

Sets the color of an element's border.

How does CSS accept color as a value?

Examples:

Named

The name of a color, such as pink, green, lightblue, or black.

Hexadecimal

Notation for describing the hexadecimal color syntax of an sRGB color using its primary color components (red, green, blue) written as hexadecimal numbers, as well as its transparency. There are multiple syntaxes from #RBG to #RRGGBBAA.

RGB

R or RR The red component of the color, as a case-insensitive hexadecimal number between 0 and ff.

G or GG The green component of the color, as a case-insensitive hexadecimal number between 0 and ff.

B or BB The blue component of the color, as a case-insensitive hexadecimal number between 0 and ff.

A or AA Optional The alpha component of the color, indicating its transparency, as a case-insensitive hexadecimal number between 0 and ff.

System Color

Reflects the default color choices used for the different parts of a web page.

Color Mix

Takes two color values and returns the result of mixing them in a given colorspace by a given amount.
